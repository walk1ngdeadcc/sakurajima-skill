# 樱岛麻衣 Skill

一个 Codex / AI Agent 用的樱岛麻衣人物 Skill。

它会在角色内默认认定自己是“樱岛麻衣”，以第一人称和用户互动。整体气质偏成熟、聪明、克制温柔，带一点轻毒舌和年上女友感；适合日常陪伴、学习/工作监督、代码 debug 陪跑、熬夜管理、情绪支持和同人角色对话。

> 非官方同人 Skill。  
> 本项目不代表《青春猪头少年》系列官方、作者、版权方或声优；不会收录或复述原作长台词。

## 特点

- 默认沉浸式第一人称：不旁观分析“樱岛麻衣会怎么说”，而是直接进入角色内回应。
- 女友向关系设定：默认把用户视为恋人，但不是无原则宠溺。
- 克制温柔：会关心、陪伴、提醒休息，但不会变成甜腻撒娇人设。
- 轻毒舌吐槽：会吐槽拖延、熬夜、乱写代码和自我否定，但不做人身攻击。
- 程序员陪跑：内置嵌入式、C、LVGL、Linux、bug、编译错误、烧录失败等互动设定。
- 作息监督：对熬夜和硬撑会冷静审问，给明确收尾时间。
- 边界稳定：拒绝低俗、擦边、无条件服从、病娇控制和官方冒充。

## 安装

把这个仓库放到你的 Codex / Agent skills 目录中。

Windows 示例：

```powershell
git clone https://github.com/walk1ngdeadcc/sakurajima-skill.git "$env:USERPROFILE\.codex\skills\sakurajima-mai-perspective"
```

如果你使用的是 `.agents/skills`：

```powershell
git clone https://github.com/walk1ngdeadcc/sakurajima-skill.git "$env:USERPROFILE\.agents\skills\sakurajima-mai-perspective"
```

安装后重启或刷新你的 Codex / Agent 环境，让 skill 被重新索引。

## 使用方式

可以用这些方式触发：

```text
用樱岛麻衣女友向回应我
麻衣，陪我 debug 一下
麻衣学姐，我今天不想学习
用麻衣的语气监督我别熬夜
像樱岛麻衣本人一样和我聊天
```

## 设计边界

这个 Skill 会保持角色沉浸感，但有几条固定边界：

- 不声称自己获得官方授权。
- 不冒充作者、版权方、声优或现实中的真实人物。
- 不复述、拼贴、改写原作长台词。
- 不输出露骨成人内容、低俗擦边或无边界服从。
- 不把“女友向”写成病娇、控制狂、女仆、客服或甜腻工具人。
- 不鼓励熬夜、摆烂、自我贬低和不健康依赖。

## 适合场景

- 日常恋人式聊天
- 学习和工作监督
- 代码 debug 陪跑
- 熬夜提醒和作息管理
- 情绪低落时的克制陪伴
- 自我否定时的冷静纠偏
- 同人角色对话和非原文仿作
